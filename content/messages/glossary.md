> 초안. 가나다순입니다.

| 말 | 뜻 |
|---|---|
| 감사 포인트 | 멤버끼리 고마움을 표시하는 포인트. 남에게만 줄 수 있고, 정해진 기간 안에 쓰지 않으면 사라집니다. 모은 포인트는 경매에서 씁니다. |
| 공동탐색연구 | 기수 초반, 정기모임 발제를 듣고 조별로 토론하는 과정 (8기 기준) |
| 기수 | 선발된 새 멤버가 함께 보내는 두세 달의 과정. 일종의 통과의례이자, 다오랩과 결을 맞추는 시간입니다. |
| 길드 | 크루가 다오랩의 취지와 관련된 주제로 열고 참여하는 소그룹. 기수와 상관없이 저마다의 기간과 방식으로 움직입니다. |
| 다오(DAO) | 탈중앙화된 자율 조직. 다오랩에서는 미래 조직을 가리키는 상징으로 씁니다. [다오는 상징이다](../philosophy/dao-as-metaphor.md) |
| 다오랩데이 | 매달 한 번 열리는 전체 모임. 네트워킹과 인사이트를 나눕니다. |
| 다오 쇼케이스 | 기수의 조별 연구 결과를 공개 발표하는 자리 |
| 루키 | 기수 과정을 밟고 있는 신규 멤버 |
| 벙개 | 누구나 여는 한 번짜리 모임 |
| 셰르파 | 직전 기수를 마친 멤버 가운데 지원한 사람들이 맡는, 다음 기수의 안내 역할. 한 기수 동안만 맡고 순환합니다 (4기부터). [운영진에서 셰르파로](../story/sherpa.md) |
| 시즌 | 여러 기수를 묶은 큰 단위. 시즌1은 1–5기(2024.1–2025.6, 커뮤니티 실험), 시즌2는 6기부터(조직 실험) |
| 온보딩 | 기수 초반에 다오랩을 이해하고, 서로 알아 가고, 조를 짜는 기간 |
| 운영진 | 2024년까지 다오랩을 운영한 상설 그룹. 2025년 초 셰르파 체제로 바뀌었습니다. |
| 조별 연구 | 기수 동안 조를 나눠 미래 조직과 커뮤니티의 한 주제를 연구하는 활동 |
| 크루 | 기수를 수료한 정식 멤버. 길드를 열고 다오랩 운영에 참여할 수 있습니다. |
| 클럽 | 연구 주제와 상관없는 취미 소모임 |
| 트레일메이커 | 2025년에 실험한 1년 단위 운영 조직. 두 분기 만에 멈추고 길드로 옮겨 갔습니다. 셰르파의 옛 이름이 아닙니다. |
| 히말라야 선언문 | 2024년에 쓴 다오랩의 선언문. [선언문](../manifesto.md) |
