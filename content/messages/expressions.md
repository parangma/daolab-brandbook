## 설립자의 말

| 표현 | 뜻 |
|---|---|
| 미래 조직 실험실 | 다오랩의 정의. 느슨한 연대, 실행 조직, 실험실이라는 세 특징을 가진다 |
| 연구의 주체이면서 연구의 대상 | 다오랩은 미래 조직을 연구하면서, 그 연구를 자기 자신에게 실험한다 |
| 우리는 친목으로 모인 게 아니다 | 분명한 목표를 이루려고 만든 실행 조직이다 |
| 언제든 나가도 된다, 들어오는 건 쉽지 않다 | 느슨한 연대. 강제하지 않지만, 선발을 거쳐 들어온다 |
| 정답도 없고 실패해도 괜찮다 | 실험실이라는 정체성 |
| 뭘 해 줄지가 아니라 뭘 안 해 줄지 | 빠질 줄 아는 리더십 |
| 내가 하고 싶었던 일을 길드로 | 운영진이 아니라 길드가 다오랩을 움직이는 방식 |
| 기록하지 않으면 기여하지 않은 것이다 | 투명성 원칙의 캐치프레이즈 |
| 끝이 있어야 한다 | 기수제가 에너지를 지키는 이유 |
| 500년 된 주식회사에 모든 걸 걸어야 하나 | 다오랩이 대안 조직을 찾는 이유 |

## 멤버들의 말

운영진과 셰르파에게 "나에게 다오랩이란"을 물었을 때 나온 말들입니다.

| 표현 | 말한 사람 |
|---|---|
| 샌드박스, 율도국, 정화수 | 1기 운영진 |
| 좋은 사람들과 함께하는 흥미로운 실험. 전체가 하나의 거대한 실험 | 1기 운영진 |
| 사람 자체가 보상이었다 | 셰르파 |
| 예습 | 셰르파 |
| 첫사랑 같은 공간 | 셰르파 |
| 그냥 실험. 계속 새로움을 시도하는 곳 | 셰르파 |

- **샌드박스, 율도국**은 이상을 마음껏 실현해 보는 곳이라는 뜻으로, **예습**은 미래의 조직과 일을 미리 겪어 보는 곳이라는 뜻으로 쓰였습니다.
- 이 말들은 공식 문구가 아닙니다. 다오랩이 안에서 어떻게 느껴지는지 보여 주는 말이라, 소개 글에 인용으로 곁들이기 좋습니다.
